## Project Overview

This is a Truffle-based implementation of the Lox programming language, developed as part of the "Build Your Own Programming Language" (BYOPL) course at HPI. The language is implemented using GraalVM's Truffle framework and uses bytecode compilation for execution.

## Build and Development Commands

### Build and Compile
```bash
./mvnw package                    # Compile the project
./mvnw clean                      # Clean build artifacts
./mvnw test                       # Run all tests
```

### Running Lox Programs
```bash
./lox <program.lox>                                  # Execute a Lox program
./lox -c 'print true;'                               # Execute inline code
./lox --cpusampler <program>                         # Run with CPU sampling
./lox --cputracer <program>                          # Run with CPU tracing
./lox --dap <program>                                # Run with DAP debugging support
./debuglox <program>                                 # Run with Java debugger support (attach in VSCode)
./mvnw exec:java -Dexec.args="-c 'print true;'"     # Run via Maven
```

### Benchmarking
Use the `harness.lox` script to run benchmarks:
```bash
./lox harness.lox <benchmark> <num-iterations> <inner-iterations>
```

Example benchmarks available: `queens`, `sieve`, `towers`, `permute`, `list`

### Testing
```bash
./mvnw test                                    # Run all tests
./mvnw test -Dtest=ClassName                   # Run a specific test class
./mvnw test -Dtest=ClassName#methodName        # Run a single test method
```

### GraalVM Native Image
```bash

```

## Architecture

### Language Structure

The Lox implementation follows this architecture:

1. **Parsing (ANTLR4-based)**: `src/main/antlr4/de/hpi/swa/lox/parser/Lox.g4`
   - ANTLR4 generates lexer and parser from the grammar
   - Generated files go to `target/generated-sources/antlr4/`

2. **Bytecode Compilation**: `src/main/java/de/hpi/swa/lox/parser/LoxBytecodeCompiler.java`
   - Visitor pattern over ANTLR parse tree
   - Compiles AST to Truffle Bytecode DSL
   - Handles variable scoping (local, global, closure variables)
   - Uses `LoxLexicalScope` inner class for tracking variable scopes
   - Function depth tracking for closure materialization

3. **Bytecode Execution**: `src/main/java/de/hpi/swa/lox/bytecode/LoxBytecodeRootNode.java`
   - Generated by Truffle Bytecode DSL annotation processor
   - Contains all bytecode operations (LoxAdd, LoxMultiply, LoxCallFunction, etc.)
   - Framework handles optimization and JIT compilation

4. **Runtime Data Types**: `src/main/java/de/hpi/swa/lox/runtime/data/`
   - `LoxObject`: Base object with properties
   - `LoxClass`: Class definitions with methods
   - `LoxFunction`: Callable functions with closure support
   - `LoxArray`: Array implementation with iterator support
   - `LoxNumber`: Numeric values
   - `Nil`: Null value representation

5. **Language Registration**: `src/main/java/de/hpi/swa/lox/LoxLanguage.java`
   - `@TruffleLanguage.Registration` registers "lox" as a language
   - Creates `LoxContext` for execution
   - Defines built-in functions (clock, Number, String, load, round, lookup)

### Key Implementation Details

**Variable Scoping System**:
- `LoxBytecodeCompiler.LoxLexicalScope` manages variable resolution
- Three types of variable access:
  - Local variables: Direct bytecode local access
  - Closure variables: Materialized frame access across function boundaries
  - Global variables: Global scope operations
- `functionDepth` tracking determines if variable needs frame materialization

**Array Implementation**:
- Custom emoji syntax: `👉👈` for empty array, `👉1,2,3👈` for array literals
- Array indexing: `arr👉0👈` to access elements
- Iterator support for `for-of` and `for-in` loops
- Interoperability via `@ExportLibrary(InteropLibrary.class)`

**Built-in Functions**:
- Implemented as Truffle nodes in `src/main/java/de/hpi/swa/lox/nodes/`
- Use `@Specialization` annotations for type-specific optimizations
- Generated code in `target/generated-sources/annotations/`

## Lox Language Specifics

### Custom Syntax Extensions

- **Arrays**: `👉👈` (empty), `👉1,2,3👈` (literal), `arr👉0👈` (indexing)
- **Class inheritance**: `class Child 🤝 Parent { }`
- **Self reference**: Use `self` instead of `this` in methods
- **For-of/For-in loops**: `for (var elem of arr)` and `for (var idx in arr)`
- **Comments**: Both `/* block */` and `// line` comments supported
- **Required for-loop condition**: For loops must have a condition (no `break` statement)

### Migration Tools

Scripts to convert standard Lox syntax to this implementation's syntax:
- `migration_boring_lox_to_amazing_lox.sh` (Linux/Unix)
- `migration_boring_lox_to_amazing_lox_macos.sh` (macOS)

## Implementation Notes

- Java 21 required (uses records, switch expressions)
- GraalVM 24.2.0-SNAPSHOT for best performance
- REPL mode: Set `isRepl=true` in environment to auto-print expression values
- Generated sources are created by: ANTLR4 plugin, Truffle DSL annotation processor
- Source attribution tracking: All AST nodes track source positions for debugging
